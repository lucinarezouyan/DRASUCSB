# DRAS UCSB Website

A responsive one-page class-project website for DRAS UCSB.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Before publishing
1. Replace `drasucsb@example.com` with the contact email you want to show.
2. Add verified UCSB / Isla Vista resource links if you want the Resources section to be clickable.
3. Keep the prototype disclaimer unless the service actually exists and is staffed.
4. Upload these three files to a GitHub repository and enable GitHub Pages.

The site currently does **not** collect or submit sensitive information.
