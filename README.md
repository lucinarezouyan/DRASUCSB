# DRAS UCSB Website — Updated Prototype

This is a static class-project prototype. It does **not** collect or transmit reports.

## What changed
- Replaced the old anonymous-admin/pattern concept with a survivor-controlled report timeline.
- Added official reporting pathways for:
  - UCSB Title IX / Discrimination & Harassment Prevention
  - UCSB Police Department
  - Santa Barbara County Sheriff — Isla Vista Foot Patrol
- Added current support resources for:
  - UCSB CARE
  - CARE's Isla Vista / Gaucho Support Center location
  - STESA / Isla Vista Survivor Resource Center
  - UCSB CAPS
  - Isla Vista Community Services District Survivor Resources Hub
- Removed the founder/personal-name contact block from the public site.

## GitHub Pages
Upload the contents of this folder to the repository root:
- index.html
- styles.css
- script.js
- assets/

GitHub Pages should be set to `main` and `/(root)`.

## Important
Phone numbers, addresses, and procedures can change. The site links to official pages so future users can confirm the latest information.
